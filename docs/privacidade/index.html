Política de privacidade do Vedra

Vigente desde 20 de outubro de 2026 · English version

Resumo: o Vedra não coleta, não guarda fora do seu aparelho e não compartilha nenhum dado pessoal. O app não tem permissão de acesso à internet.

Quem somos

O Vedra é um aplicativo para Android desenvolvido pela AuraDev (auradevcode.com.br). Ele bloqueia, com PIN ou digital, os aplicativos que você escolher.

Uso do serviço de Acessibilidade

Para bloquear um app no instante em que ele abre, o Vedra usa a API de Acessibilidade do Android (AccessibilityService). Por meio dela, o Vedra recebe apenas o nome do pacote do app que está em primeiro plano (por exemplo, com.whatsapp).

  • O Vedra não lê o conteúdo das telas, mensagens, textos, fotos, senhas, toques ou digitação.
  • O nome do app em primeiro plano é usado só para decidir se aquele app deve ser bloqueado. Ele não é enviado a ninguém.
  • O Vedra não usa a Acessibilidade para clicar, digitar ou agir em outros apps.
  • Você pode desligar o serviço a qualquer momento em Configurações → Acessibilidade.

Dados guardados no aparelho

  • PIN: guardado só como hash criptográfico (PBKDF2 com uma chave do Android Keystore que não sai do aparelho). O PIN em si nunca é guardado.
  • Lista de apps protegidos e configurações (como a regra de rebloqueio).
  • Contagem de tentativas erradas, para o atraso de segurança.

Esses dados ficam só no armazenamento privado do app, não entram em backup na nuvem e são apagados quando você desinstala o Vedra ou limpa os dados dele.

Biometria

A digital é verificada pelo próprio Android. O Vedra nunca recebe nem guarda a sua digital: só recebe do sistema o resultado (sucesso ou falha).

Lista de apps instalados

Para você escolher o que proteger, o Vedra lista os apps que têm ícone na tela inicial. Essa lista é usada só dentro do aparelho.

Compartilhamento e terceiros

O Vedra não tem anúncios, análise de uso, rastreamento ou bibliotecas de terceiros que coletem dados. Como não tem permissão de internet, ele não consegue enviar nada para fora do aparelho.

Crianças

O Vedra não é direcionado a crianças e não coleta dados de ninguém.

Seus direitos (LGPD)

Como nenhum dado pessoal é tratado fora do seu aparelho, não há dados nossos sobre você para acessar, corrigir ou excluir. Para apagar tudo o que o Vedra guarda no aparelho, desinstale o app ou limpe os dados dele.

Alterações

Se esta política mudar, a nova versão será publicada nesta página, com a data de vigência atualizada.
